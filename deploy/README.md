# انتشار روی سرور و دامنه‌ی shimaazimi.ir

بعد از این راه‌اندازی یک‌باره، هر پوش به شاخه‌ی `main` سایت را خودکار بیلد می‌کند و روی سرور می‌گذارد.

روند انتشار این است: گیت‌هاب سایت را می‌سازد، خروجی را با SSH در یک پوشه‌ی تازه روی سرور کپی می‌کند، و بعد در یک لحظه نسخه‌ی زنده را به آن پوشه منتقل می‌کند. پنج نسخه‌ی آخر روی سرور می‌مانند تا اگر لازم شد، بشود به نسخه‌ی قبلی برگشت.

## ۱. دامنه (DNS)

در پنل دامنه‌ی `shimaazimi.ir`، دو رکورد بساز:

| نوع | نام | مقدار |
|---|---|---|
| `A` | `@` | IP سرور |
| `A` | `www` | IP سرور |

اگر سرورت IPv6 دارد، دو رکورد `AAAA` هم با همین نام‌ها بساز. اعمال تغییرات DNS ممکن است از چند دقیقه تا چند ساعت طول بکشد.

## ۲. راه‌اندازی سرور (یک بار)

این روش برای Ubuntu یا Debian نوشته شده است. پوشه‌ی `deploy` را به سرور کپی کن و این را اجرا کن:

```bash
sudo bash deploy/setup-server.sh
```

این اسکریپت کارهای زیر را انجام می‌دهد:

- Nginx و certbot را نصب می‌کند.
- یک کاربر `deploy` می‌سازد که فقط به پوشه‌ی سایت دسترسی دارد.
- سایت را روی پورت ۸۰ سرو می‌کند.

## ۳. کلید SSH برای انتشار

روی کامپیوتر خودت یک کلید جدا فقط برای انتشار بساز، و برای آن رمز نگذار:

```bash
ssh-keygen -t ed25519 -f deploy_key -N "" -C "github-deploy"
```

دو فایل ساخته می‌شود:

- **`deploy_key.pub` (کلید عمومی):** محتوایش را روی سرور در `/home/deploy/.ssh/authorized_keys` بگذار.
- **`deploy_key` (کلید خصوصی):** فقط در گیت‌هاب، در مرحله‌ی بعد. آن را جای دیگری نفرست و در مخزن هم نگذار.

## ۴. تنظیمات مخزن در گیت‌هاب

به **Settings ← Secrets and variables ← Actions ← New repository secret** برو و این‌ها را اضافه کن:

| نام | مقدار |
|---|---|
| `SSH_HOST` | IP سرور |
| `SSH_USER` | `deploy` |
| `SSH_KEY` | کل محتوای فایل `deploy_key` |
| `SSH_PORT` | فقط اگر پورت SSH سرورت ۲۲ نیست |

## ۵. HTTPS

وقتی دامنه به سرور اشاره کرد، روی سرور اجرا کن:

```bash
sudo certbot --nginx -d shimaazimi.ir -d www.shimaazimi.ir --redirect
```

certbot گواهی را خودش تمدید می‌کند.

## ۶. اولین انتشار

کد را به `main` پوش کن، یا در تب **Actions** گزینه‌ی **Deploy to server ← Run workflow** را بزن. بعد از سبز شدن، سایت روی `https://shimaazimi.ir` بالا است.

## اگر مشکلی پیش آمد

- **خطای اتصال SSH در Actions:** سرورهای ایرانی گاهی اتصال ورودی از خارج را محدود می‌کنند و سرورهای گیت‌هاب در خارج‌اند. پورت SSH را در فایروال سرور و دیتاسنتر بررسی کن. اگر باز هم وصل نشد، روش دیگر این است که خود سرور کد را از گیت‌هاب بکشد.
- **برگشت به نسخه‌ی قبل:** روی سرور اجرا کن:

```bash
cd /var/www/shimaazimi.ir/releases && ls -1t
```

بعد نسخه‌ی دلخواه را زنده کن:

```bash
ln -sfn /var/www/shimaazimi.ir/releases/<نام-نسخه> /var/www/shimaazimi.ir/current
```
